# 🎧 プレイヤー向けガイド

ゲーム内でFFBLを**使う人**向けです。Discord側のルームを作る方は[オーナー向けガイド](donos.ja.md)をご覧ください。

## 必要なもの

- **XIVLauncher/Dalamud**で起動したファイナルファンタジーXIV。
- 同じPCで開いた**Discordアプリ**（ブラウザ版だけでは不可）。
- **チャンネルオーナー**から個別に届く**接続コード**（`FFBL1-`で始まります。パスワードと同じ扱いで！）
- **スクリーン**を使う場合（任意）：**Penumbra**プラグインとミニオン**Plush Cushion**。

> 🎧 **聞くだけなら？** インストール不要。Discordのボイスルームに入るだけです。

## ステップ1：テスター招待を承認
オーナーがあなたを**アプリのテスター**に追加します。Discordに招待が届くので**承認**してください。承認しないとプラグインが接続できません。

## ステップ2：プラグインをインストール
1. ゲーム内で `/xlsettings` と入力。
2. **Experimental**を開く。
3. **カスタムプラグインリポジトリ**に次のURLを貼り付け、**+**、**保存**の順にクリック：

```
https://raw.githubusercontent.com/yurammaruy/FFBL/main/repo.json
```

4. `/xlplugins` と入力し、*すべてのプラグイン*から**FFBL**を探して**インストール**。

## ステップ3：接続
1. `/ffbl` と入力してiPodを開く。
2. 接続画面に**接続コード**を貼り付け、**Aplicar codigo**（コードを適用）をクリック。すべて自動で入力されます。
   - **OMNE**（近接ボイス）：**OMNE**タブを開いて有効にし、**Conectar**をクリック（情報はコードに含まれています）。
   - 🔒 安全のため、FFBLはキャラクターがログアウトするたび（ゲーム終了時も）に**コードを忘れます**。次回は貼り直してください。
3. **接続**をクリック。
4. **Discord**のウィンドウで**認証**をクリック。
5. 「接続しました（あなたの名前）」と出たら、ホイールの**MENU**でプレイリストを開く。

## 使い方

| ホイールのボタン | 動作 |
|---|---|
| **MENU** | 接続画面とプレイリストの切り替え |
| ⏮ | 前の曲 |
| ⏭ | スキップ |
| ⏯ | 再生／一時停止 |
| **中央ボタン** | リクエスト入力欄を開く（曲名またはYouTubeリンク） |
| **+ / −** | 音量 |
| 下隅のアイコン | ウィンドウを閉じる（`/ffbl`と同じ） |

プラグインの言語は**Idioma**タブで変更できます。

## スクリーン（任意）
1. **Penumbra**をインストールして有効にしておく。
   次に、ファイル [`penumbra/Background_Screen.pmp`](../penumbra/Background_Screen.pmp) を**一度だけインポート**します。Penumbraを開き、ウィンドウにファイルをドラッグ＆ドロップ（またはインポートボタン）。一度だけで大丈夫です。ほかは何も変更しないでください。
2. **Projeção**タブでスクリーン作成ボタンをクリック。FFBLが*Plush Cushion*を呼び出してスクリーンに変えます。
3. 表示内容を選択：標準画像、曲のジャケット、またはPC内の画像。
4. **−**と**+**でサイズ・位置・回転を調整。

FFBLを入れていない人には、通常のミニオンのまま見えます。

## OMNE（近接ボイス）
**OMNE**タブにあり、**標準では無効**です。説明は[トップページ](../README.ja.md)をご覧ください。仲間と近接ボイスを使いたいときに有効にしてください。

## よくある問題

| 症状 | 対処 |
|---|---|
| 接続時に `invalid_request` / 「Missing redirect_uri」 | Discordポータルで使用中のアプリの **OAuth2 → Redirects** に `http://localhost` を追加し、**Save Changes** をクリック。Client IDが正しいアプリのものかも確認してください。 |
| 「Discordを探しています」から進まない | Discordアプリ（ブラウザ版ではなく）を開いて再試行。 |
| 認証の画面が出ない | テスター招待を承認したか確認。 |
| Webhookリンクが無効 | `https://discord.com/api/webhooks/` で始まるリンク全体を貼り付ける。 |
| スクリーンが出ない | Penumbraが入っていて有効か確認。 |
| 音楽が流れない | オーナーにボットが起動しているか確認してもらう。 |

解決しない場合は、スクリーンショット付きでGitHubの**Issue**を作成してください。
